# SOL Explorer — Grade 5

An educational Android starter for self-study aligned to Virginia Grade 5 Standards of Learning. It includes chapter-by-chapter maps for Mathematics, English, Science, and History & Social Science; visual lesson cards; answer explanations; a sample test mode; and an offline-first structure ready for progress persistence.

## Run

Open this folder in Android Studio Ladybug or newer, let Gradle sync, and run the `app` configuration on an emulator or Android device (API 26+).

## Content scope

The app is an educational companion, not an official VDOE product. Standards labels are starter references: Mathematics follows the 2023 Virginia Mathematics SOL; Science content follows the 2018 Grade 5 Science SOL while VDOE implementation and assessment timelines evolve; English and History/Social Science are organized around commonly used Grade 5 strands and Virginia identifiers. Confirm local pacing with the child’s teacher.
